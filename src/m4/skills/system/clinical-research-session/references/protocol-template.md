# Protocol template

```markdown
# Protocol: <title>

## Research question
<one specific, answerable question>

## Design
<descriptive | comparative | predictive | exploratory>; dataset and version

## Population
- Inclusion: <criteria>
- Exclusion: <criterion - reason>
- Unit of analysis and time zero: <e.g. first ICU stay per patient; ICU admission>

## Variables
- Primary outcome: <definition, source, follow-up window>
- Exposure: <definition, time window, comparator>
- Covariates: <each with definition and the time it is measured>
- Secondary outcomes: <or none>

## Analysis plan
1. <step - method - why>

## Biases and limitations
- <risk - how the design handles it>

## Skills used
- <skill> - <concept it defines>
```
